# AI_Weather-City-information-Agent
## 📖 Description
This project is an AI-powered agent that provides real-time weather updates and detailed city information based on user queries. It uses Large Language Models (LLMs) with external APIs to fetch live weather data and city details, enabling users to interact through natural language.


## 🎯 Objective
-Provide real-time weather information.
-Retrieve city details using AI.
-Answer user queries in natural language.
-Integrate multiple APIs into a single AI agent.

## 🛠️ Technologies Used
-Python
-LangChain
-OpenAI API
-Weather API 
-REST Countries API
-Requests
-Streamlit
-dotenv

## ⚙️ Features
-Live weather updates.
-City information (country, capital, population, timezone).
-Temperature, humidity, wind speed, and weather conditions.
-Natural language interaction.
-User-friendly Streamlit interface.
-Fast API-based responses.

## ▶️ Usage
-Launch the application.
-Enter a city name.
-Ask questions like:
        "What's the weather in Mumbai?"
        "Tell me about Tokyo."
-The AI agent retrieves live weather and city information.
-The response is displayed in a simple, interactive interface.

## 📊 Results
-Successfully provides real-time weather updates.
-Retrieves accurate city information.
-Delivers fast, AI-generated responses with an interactive user interface.

## 📌 Conclusion
The AI Weather & City Information Agent demonstrates how LLMs and external APIs can be combined to create an intelligent assistant that provides real-time weather forecasts and city details through natural language conversations.
